# Picnic MCP – Home Assistant add-on

Home Assistant add-on-repository met één add-on: **Picnic MCP**. Daarmee kan Claude in je Picnic-account
zoeken, de aanbiedingen van deze week bekijken en je winkelmandje vullen. Afrekenen doe je zelf in de app.

[![Add repository](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Frubenhartong%2FPicnic-mcp)

Zie [picnic-mcp/DOCS.md](picnic-mcp/DOCS.md) voor installatie en beveiliging.

Gebruikt [mcp-picnic](https://github.com/ivo-toby/mcp-picnic) (MIT) en de onofficiële Picnic-API;
Picnic kan die zonder aankondiging wijzigen.
